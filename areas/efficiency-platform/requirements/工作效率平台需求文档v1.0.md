
# 迭代管理平台

## 项目概述

面向公司内部开发的效率迭代平台，实现迭代管理、测试单管理、发布单管理、工作项管理等功能。

**重要说明：**

- 工作项数据从云效平台同步获取，本平台不提供工作项的创建、修改功能
    
- 产品线、用户信息为内置数据，暂不提供管理功能
    
- 用户通过钉钉OAuth登录系统
    

## 核心功能模块

### 1. 迭代管理

- 新建/修改迭代，关联工作项
    
- 迭代负责人需要人工指定
    
- 迭代状态流转：待立项 →  开发中，待提测 → 测试中  → 测试完成，已出包。
    
- 每个流转状态支持消息通知
    
- 支持创建提测单
    
- 迭代列表查询、筛选。
    

### 2. 提测单管理

- 新增/修改提测单，关联迭代
    
- 测试单状态：待开始 → 测试中 → 已完成
    
- 测试单列表查询、筛选
    
- 每个流转状态支持消息通知
    

### 3. 发布单管理

- 一个客户建一个发布单
    
- 新增/修改发布单，关联一个提测单
    
- 所有应用的发布状态需要维护，当所有应用状态都为完成时，发布单结单，发个钉钉通知到对应产品群。
    
- 发布单列表查询、筛选。
    
- 每个流转状态支持消息通知，
    

### 4. 工作项管理

- 从云效平台同步工作项数据（手动/定时同步）
    
- 工作项列表查询、筛选、导出
    
- 支持跳转到云效平台查看详情
    

### 5. 用户认证与权限

- 钉钉OAuth登录
    
- 角色：普通用户、管理员
    
- 权限控制：列表查询、创建、修改、删除


### 6.应用发布历史

- 发布记录
    

## 数据模型

### 核心实体

- **迭代（Iteration）**：迭代基本信息，关联产品线、负责人、工作项
    
- **测试单（TestOrder）**：测试单元信息，关联迭代
    
- **发布单（ReleaseOrder）**：发布单元信息，关联迭代和测试单
    
- **工作项（WorkItem）**：从云效同步的工作项数据
    
- **产品线（ProductLine）**：产品线配置信息
    
- **应用（APP）：**应用列表
    
- **用户（User）**：用户信息，通过钉钉OAuth创建
    

### 关联关系

![image](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/a/p20mm7KBDU79Eo9W/036795b3fcd044cba4731e495a9e50e20921.png)

- 应用 ↔ 产品线 多对多关系
    
- 工作项 ↔  产品线 多对一关系
    
- 迭代 ↔ 工作项：多对多关系（通过 IterationWorkItem）
    
- 迭代 ↔  提测单：一对多关系
    
- 提测单↔  发布单：一对多关系
    
- 发布单↔ 应用： 多对多
    
- 发布单↔ 产品线： 多对多
    

### 状态枚举

- **迭代状态**：待立项 →  开发中，待提测 → 测试中  → 测试完成，已出包。
    
- **测试单状态**：待开始、测试中、已完成
    
- **发布状态**：待发布、已发布
    
- **发布单-应用发布状态：** 已发布、未发布
    
- **工作项类型**：跟云效同步
    
- **工作项状态**：跟云效同步
    

## 技术栈

### 前端

- **框架**：React + TypeScript
    
- **UI库**：Ant Design
    
- **路由**：React Router
    
- **HTTP客户端**：Axios
    
- **状态管理**：Zustand/Redux
    

### 后端

- **语言**：Python 3.12.11+
    
- **Web框架**：FastAPI
    
- **ORM**：SQLAlchemy
    
- **数据库**：MySQL 8.0+
    
- **数据迁移**：Alembic
    

### 认证与授权

- **OAuth登录**：钉钉OAuth（使用 JustAuth-Python）
    
- **Token认证**：JWT（7天过期，支持刷新）
    

### 数据同步

- **云效同步**：requests + APScheduler
    
- **同步频率**：每天凌晨2点自动同步
    

### 部署

- **容器化**：Docker
    
- **Web服务器**：Uvicorn
    
- **反向代理**：Nginx
    

## 开发环境要求

### 前端

- Node.js 16+
    
- npm 或 yarn
    
- TypeScript 4.5+
    

### 后端

- Python 3.12.11+
    
- MySQL 8.0+
