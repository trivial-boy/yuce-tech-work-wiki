# 对外状态回复模板

## 使用场景

- 同事来问某个需求、项目、缺陷、联调事项目前进展如何。
- 需要快速整理成一段可以直接发出去的回复。

## 回复结构

### 标准版

```text
这个事项目前已经完成 {{已完成部分}}，现在正在处理 {{当前进行中}}。
如果没有新的阻塞，预计会在 {{计划完成时间}} 前完成 / 给到结果。
当前风险或依赖是：{{风险/依赖}}。
```

### 简洁版

```text
目前已经完成 {{已完成部分}}，现在在推进 {{当前进行中}}，预计 {{计划完成时间}} 完成。
```

### 谨慎版（信息未完全确认时）

```text
我这边先同步下当前已确认的进展：{{已确认进展}}。
剩余部分还在继续跟进，预计 {{计划完成时间}} 前再给你一个更完整的结果。
如果中间有变化，我会第一时间同步。
```

### 存在阻塞时

```text
目前主体已经推进到 {{当前阶段}}，但现在卡在 {{阻塞点}}。
我这边正在协调 / 处理，理想情况下预计 {{计划完成时间}} 恢复或完成。
如果这个阻塞提前解除，我会同步最新进展。
```

## 回答前检查

- 已完成部分是否真实可确认
- 当前进行中的事项是否准确
- 计划完成时间是否有依据
- 是否存在外部依赖、阻塞或待确认项
- 如果信息不完整，优先用“谨慎版”，不要编造进度

## 语气约定

- 简洁、自然、可信
- 不夸大，不承诺没有把握的时间
- 尽量让对方知道：`做到了哪里`、`接下来做什么`、`什么时候再同步`

## 常见字段

- 事项名：
- 已完成部分：
- 当前进行中：
- 当前阶段：
- 阻塞点：
- 风险 / 依赖：
- 计划完成时间：
- 下次同步时间：
